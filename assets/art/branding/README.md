# Logo officiel Beherit — LOGO-001

Sources fournies par le propriétaire le 30 octobre 2026.
`beherit_square_source.png` et `beherit_round_source.png` sont des copies exactes
des deux PNG 1254 × 1254 transmis. La version ronde conserve son canal alpha.

`tools/prepare_branding.gd` prépare mécaniquement les formats d’export : carré192,
avant-plan432 avec logo rond288 centré, fond432 noir #000000, démarrage rond320.
Aucun redessin, changement de couleur ou recadrage du contenu des images sources.
Les mipmaps concernent uniquement les grandes sources présentées dans le laboratoire.
Le fichier carré192 est l’icône Godot et Android classique. Les calques432 servent
à l’icône adaptative et au démarrage système Android. Les sources restent archivées
pour d’autres dimensions ultérieures.
